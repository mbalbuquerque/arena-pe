# Arena PE — Catálogo inicial de 7 eventos

Esta versão preserva a identidade visual e exibe os sete projetos fornecidos na seção Eventos.

## Publicação
Copie `index.html`, `styles.css`, `script.js` e `events-data.js` para a raiz do site no Netlify.

## Ajustes antes da divulgação
- Confirme datas e status no arquivo `events-data.js`.
- Substitua os placeholders pelas artes oficiais usando a propriedade `imagem`.
- O Treino Sítio de Mainha está sem data confirmada.
- O Corra Por Você foi classificado como projeto permanente, não como evento com data.
- Os botões não prometem inscrições abertas sem confirmação.
